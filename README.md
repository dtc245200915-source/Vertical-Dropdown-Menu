# Thực hành tạo Menu Dropdown Dọc

Bài thực hành sử dụng HTML và CSS để tạo menu dọc có menu con.

## Chức năng
- Menu chính hiển thị theo chiều dọc.
- Menu con được ẩn mặc định bằng `visibility: hidden`.
- Khi di chuột vào mục cha, menu con xuất hiện bằng `visibility: visible`.
- Menu con nằm bên phải menu chính nhờ `position: absolute`, `top: 0`, `left: 160px`.

## Chạy bài
Mở `index.html` bằng trình duyệt hoặc Live Server.
Sau đó đưa chuột vào **Sản phẩm** hoặc **Dịch vụ** để kiểm tra dropdown.
